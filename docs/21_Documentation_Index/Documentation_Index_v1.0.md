# 6. Version Control Policy

Version format:

Major.Minor

Examples:

- v1.0
- v1.1
- v2.0

Major versions indicate significant architectural or business changes.

Minor versions indicate clarifications, corrections, or incremental improvements.

---

# 7. Change Management

Every documentation update shall include:

- Version
- Author
- Date
- Reason
- Approval

Unapproved documentation changes are prohibited.
