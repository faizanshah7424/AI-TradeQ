# 1. Purpose

This glossary defines the official terminology used throughout the AI TradeQ project.

Its purpose is to ensure consistent understanding of technical, architectural, AI, security, cryptocurrency, and business terminology across all project documentation.

---

# 2. Artificial Intelligence Terms

| Term | Definition |
|------|------------|
| AI | Artificial Intelligence used for reasoning, analysis, and decision support. |
| LLM | Large Language Model used for natural language understanding and generation. |
| Agent | An AI component responsible for a specialized task within the system. |
| Multi-Agent System | A collection of AI agents collaborating to solve complex problems. |
| Prompt | Structured instruction provided to an AI model. |
| Context | Information supplied to an AI model to improve responses. |
| Hallucination | AI-generated information not supported by evidence. |
| Confidence Score | A numerical indicator expressing confidence in an AI-generated result. |

---

# 3. Cryptocurrency Terms

| Term | Definition |
|------|------------|
| Cryptocurrency | A digital asset secured by cryptography. |
| Blockchain | Distributed ledger technology that records transactions. |
| Market Cap | Total value of a cryptocurrency based on circulating supply and price. |
| OHLCV | Open, High, Low, Close, Volume market data. |
| Bull Market | Market characterized by sustained upward trends. |
| Bear Market | Market characterized by sustained downward trends. |
| Volatility | Degree of price movement over time. |
| Liquidity | Ease of buying or selling an asset without significantly affecting its price. |

# 5. Architecture Terms

| Term | Definition |
|------|------------|
| API | Application Programming Interface. |
| REST | Representational State Transfer architectural style. |
| Microservice | Independently deployable service with a specific responsibility. |
| Adapter | Component translating external provider interfaces into internal standards. |
| Orchestrator | Component coordinating workflows across services or agents. |
| MCP | Model Context Protocol used for standardized communication with tools and external services. |
