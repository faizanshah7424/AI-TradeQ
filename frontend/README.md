# Frontend Workspace (`frontend/`)

## Purpose
The `frontend/` directory contains the source code, component libraries, design systems, and client-side web application resources for the AI TradeQ SaaS user platform.

## Responsibilities
- User Interface (UI) and Dashboard views.
- Real-time trading data visualizations and charting components.
- Interaction with backend REST, gRPC, and WebSocket APIs.
- Responsive web layout and state management.
